# §1.1 Number fields

Written with Claude, from Shilov §1.1 (pp. 1–3). Examples are my own unless marked as the book's.

## §1.11 The definition

A **number field** K is a set of "numbers" with addition and multiplication, where the four arithmetic operations always give elements of K again. The field axioms:

| Axiom | Statement |
|---|---|
| 1 | α + β = β + α (addition is commutative) |
| 2 | (α + β) + γ = α + (β + γ) (addition is associative) |
| 3 | there is a 0 with 0 + α = α for every α |
| 4 | every α has a negative γ with α + γ = 0 |
| 5 | αβ = βα (multiplication is commutative) |
| 6 | (αβ)γ = α(βγ) (multiplication is associative) |
| 7 | there is a 1 ≠ 0 with 1 · α = α for every α |
| 8 | every α ≠ 0 has a reciprocal γ with αγ = 1 |
| 9 | α(β + γ) = αβ + αγ (multiplication distributes over addition) |

- **Subtraction** β − α is defined as β plus the solution of α + γ = 0 (axiom 4).
- **Division** β/α is defined as β times the solution of αγ = 1 (axiom 8), so only for α ≠ 0.
- Shilov assumes the natural numbers 1, 1 + 1, 1 + 1 + 1, ... are never zero. A footnote shows a two-element field where 1 + 1 = 0, which this rules out.
- Two fields are **isomorphic** if a one-to-one correspondence between them carries sums to sums and products to products.

## §1.12 The examples

- **Rational numbers** p/q, q ≠ 0. The integers alone are not a field: they fail axiom 8. Every field contains a copy of the rationals.
- **Real numbers.** Axioms 1–9 plus the order axioms and the least upper bound axiom.
- **Complex numbers** a + ib, with (a1 + ib1)(a2 + ib2) = (a1a2 − b1b2) + i(a1b2 + a2b1). From this rule, i² = −1. The numbers a + i0 behave exactly like the reals.

§1.13 names them: R for the reals, C for the complex numbers, and K for any field. A result proved for K holds for R and C.

## Code

In `src/complex.rs`:

- `Complex { re, im }`: a + ib with two `f64` parts.
- `add`, `mul`: Shilov's rules from §1.12c.
- `neg`, `sub`: subtraction as adding the negative, as §1.11 defines it.
- `recip`, `div`: division as multiplying by the reciprocal. `recip` returns `Err(DivisionByZero)` for 0, which is the "α ≠ 0" in axiom 8.

Each axiom has a test named after what it says, with its number in the doc line. Extra tests: i² = −1, −(−a) = a, 1/(1/a) = a, a worked subtraction and division, and the two zero-division errors.

## Floats are not quite a field

`f64` rounds, so (a + b) + c and a + (b + c) can differ in the last bits. The tests compare with `close`, which allows 1e-12 in each part. The axioms hold for the exact numbers, and the code matches them up to rounding.
