# §1.2 Problems of the theory of systems of linear equations

Written with Claude, from Shilov §1.2. Examples are my own, not the book's.

## What the section sets up

A system has k equations in n unknowns x1, ..., xn. All numbers come from a field K. k and n need not be equal.

- **Coefficients:** the numbers a_ij in front of the unknowns. i is the equation, j is the unknown.
- **Constant terms:** the numbers b_i on the right-hand side.
- **Solution:** one list of numbers c1, ..., cn that turns every equation into a true statement. One list is one solution, not n solutions.

Words for the kinds of system:

| Word | Meaning |
|---|---|
| compatible | at least one solution |
| incompatible | no solution |
| determinate | compatible, exactly one solution |
| indeterminate | compatible, at least two different solutions |

## My own examples

- x1 + x2 = 1 and x1 + x2 = 2. The left sides are always equal, the right sides are not. **Incompatible.**
- x1 + x2 = 0 and 3x1 + 3x2 = 0. Both (0, 0) and (1, -1) work, and so does any (t, -t). **Indeterminate.**
- x1 + x2 = 3 and x1 - x2 = 1. Only (2, 1) works. **Determinate.**

## The four questions

1. Is the system compatible?
2. If so, is it determinate?
3. If determinate, find the one solution.
4. If indeterminate, describe all the solutions.

Shilov's tool for answering them is the determinant, from §1.3 on.

## Where this shows up in qsense-01

qsense-01 asks whether 4 three-axis sensors can locate a magnet. That is 12 readings and 6 unknowns (3 for the position, 3 for the magnetic moment).

- **More equations than unknowns.** k = 12, n = 6. Shilov allows k and n to differ. Having more equations than unknowns does not by itself make a system determinate.
- **Not linear yet.** The field of a magnet depends on position in a nonlinear way. Near a first guess it can be approximated by a linear system. That linear system is built from the sensitivity matrix. Check this when I reach Ch. 3 (rank).
- **Noise makes it incompatible.** Real readings are noisy, so 12 equations usually have no exact common solution. In §1.2 words, the system is incompatible. Least squares (§8.8) answers a different question: which values come closest.
- **Determinate means the magnet can be located.** If two different magnet positions give the same 12 readings, the system is indeterminate and no method can tell them apart. Whether this happens depends on where the sensors sit. That is the sensor placement question in my thesis idea.
