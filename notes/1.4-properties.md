# §1.4 Properties of determinants

Written with Claude, from Shilov §1.4 (pp. 8–11). Examples are my own unless marked as the book's.

## The properties

D_j(x) means D with column j replaced by x.

| § | Property |
|---|---|
| 1.41 | A determinant equals the determinant of its transpose. |
| 1.42 | Swapping two columns flips the sign of D. |
| 1.43 | Two equal columns give D = 0, because D = −D. |
| 1.44 | D is linear in a column: D_j(λb + μc) = λD_j(b) + μD_j(c). |
| 1.45 | A common factor of a column comes outside: D_j(λb) = λD_j(b). |
| 1.46 | A column of zeros gives D = 0. |
| 1.47 | Adding λ times column k to column j (k ≠ j) leaves D unchanged. 1.47b: the same for multiples of several columns at once, each different from j. |
| 1.48 | By 1.41, every column property also holds for rows. |

## How Shilov proves them

- **1.41** uses the slope rule from §1.32. Transposing turns the matrix 180° about its main diagonal. A segment at angle α < 90° to the rows ends up at 90° − α, so its slope keeps its sign. Here α is an angle, not the permutation α1, ..., αn of §1.3.
- **1.42** is proved for neighbouring columns first, then for any two columns by a chain of 2m + 1 neighbouring swaps.
- **1.43** follows from 1.42: swapping the two equal columns changes nothing, yet flips the sign.

So §1.32 was needed to follow the proofs, even though I did not code it.

## Code

All of §1.4 is tested, not implemented: each property is a test of `det` in `src/determinant.rs`. The matrix tools are test helpers inside `mod tests`:

- `transpose`, `swap_columns`, `swap_rows`
- `with_column`: a copy with column j replaced
- `column`: column k as its own `Vec`
- `combine`: λb + μc
- `example_3x3` (D = 6) and `example_4x4` (D = 12) as shared test matrices

Columns and rows are 0-based in the code. Shilov's are 1-based.

Testing choices:

- Determinants are compared with `close_f64` (tolerance 1e-12). The helpers only copy values or do small exact arithmetic, so their tests use exact `assert_eq!` and say why.
- Most tests compare `det` with `det`, as the property states it, so no hand-calculated value is needed.
- `swap_rows_is_swap_columns_of_transpose` is §1.48 itself in code.
- `adding_a_column_to_itself_scales_det` shows why 1.47 needs k ≠ j: the column becomes (1 + λ) times itself, so D becomes (1 + λ)D.
- A linearity test is weak if every determinant in it is 0. The ones used here are not.

## Later

The helpers will move to a `matrix` module with proper `Result`s when matrices become a topic of their own (Ch. 4). Row reduction (§1.6) uses 1.42, 1.45 and 1.47 to compute D much faster than the n! definition.
