# §1.3 Determinants of order n

Written with Claude, from Shilov §1.3. Examples are my own unless marked as the book's.

## §1.31 The definition

- A square matrix of order n is n² numbers a_ij from a field K. i is the row, j is the column.
- A **term** is a product of n elements, one from each row and one from each column. Write the column indices in order 1, ..., n. The row indices α1, ..., αn are then a permutation of 1, ..., n.
- An **inversion** is a pair where a larger number comes before a smaller one. N(α) is how many there are. The book's examples: N(2, 1, 4, 3) = 2 and N(4, 3, 1, 2) = 5.
- Each term gets the sign (−1)^N: plus when N is even, minus when N is odd.
- The **determinant** is the sum of all n! signed terms.
- Order 2: a11·a22 − a21·a12. Order 3 has six terms.

Shilov also shows that two equations in two unknowns are solved by ratios of order 2 determinants. That is a preview of Cramer's rule in §1.7.

## §1.32 A second sign rule

Mark the n elements of a term in the matrix and join every pair with a segment. Shilov calls a segment "negative slope" when its right end is higher, which means a smaller row number. This is the opposite of the usual geometry convention. The sign is plus when the number of such segments is even.

It always gives the same sign as counting inversions: a segment with negative slope is exactly an inversion in the row indices.

**Read, not coded.** `sign` already covers it. The rule treats rows and columns alike, so it hints why a matrix and its transpose have the same determinant. Test that directly in §1.4.

## Code

In `src/determinant.rs`:

- `inversions`: N(α).
- `sign`: (−1)^N(α) as an `i32`.
- `identity`: the permutation (1, 2, ..., n).
- `permutations`: all n! permutations of 1, ..., n.
- `det`: the determinant by definition. It returns `Err(Empty)` for no rows and `Err(NotSquare)` when some row's length is not the number of rows.

Shilov counts from 1 and Rust from 0. The row a permutation picks is `alpha[j] - 1` as an index.

## Limits

The definition has n! terms: 6 for order 3, 3,628,800 for order 10. It is right but slow. Faster methods come later (row reduction, §1.6) and will be checked against `det`.
